## Banner elements

| Element | What it does |
| --- | --- |
| **Text** | 6 embedded fonts (Inter, Space Grotesk, JetBrains Mono, Bebas Neue, Allerta, AR One Sans). Subset per banner, so Vietnamese and other scripts work. |
| **Icon / Icon row** | 13 animated icons from the original API, plus 66 vector tech logos (Devicon) that stay sharp at any size. |
| **GitHub stat** | Current or longest streak, contributions (past year or all time), commits, stars, followers, repositories, pull requests, or **profile views**. Shows a line, animated or logo icon. |
| **Contribution graph** | The last 4–53 weeks of activity, in any color. |
| **Avatar** | Your GitHub avatar with an optional ring. |

The canvas also supports image backgrounds (17 presets, including animated ones), gradients, a custom image URL, darken and corner radius.

## API

| Endpoint | Description |
| --- | --- |
| `/api/banner?c=<config>` | Banner made in the editor. `c` is the layout as base64url(deflate(JSON)). |
| `/api/profile/banner?name=&role=&background=&tech=&skills=&streaks=&view=&user=` | Original query-string banner. `view=` is now a real views counter. |
| `/api/github/{streak,graph,stats,languages}?user=&theme=` | Profile cards |
| `/api/github/data?user=` | JSON used by the editor preview |

## Profile views

A **Profile views** stat counts each time the banner is displayed. Counts are kept per GitHub username in MongoDB (database `countview`, collection `bannerviews`).

Banners with a views counter are sent with `Cache-Control: no-cache`, so GitHub's image proxy fetches them, and counts them, on every view. Banners without a counter stay edge-cached. If the database is slow, the banner is still returned after at most 2.5 s, showing the last known count.

The demos above use a separate counter key (`vk=profilyze-readme`), so visits to this README don't count as profile views.

## Performance

- A typical banner is 20–100 KB. Fonts are subset to the glyphs used, and images are pre-optimized WebP.
- Banners without live data are cached at Vercel's edge for 30 days. Banners with GitHub stats refresh every 4 hours.
- Text, glyphs, graphs and logos are vector, so they stay sharp on any screen.

## Self-hosting

Environment variables:

| Variable | Needed for |
| --- | --- |
| `TOKEN_GITHUB` (or `GITHUB_TOKEN`) | Stars, commits, PRs, issues, languages and all-time streaks. A classic token with no scopes is enough. Without one, streaks, contributions and the graph still work through GitHub's public contributions page. |
| `MONGODB_URI` | The profile views counter, and `npm run sync:assets` |

```bash
npm install
npm run dev   # http://localhost:3000
```

### Assets

Raster backgrounds and animated icons are listed in `lib/assets.json`. `npm run sync:assets` maintains that file:

```bash
npm run sync:assets                                                         # pull every background/technical from MongoDB
npm run sync:assets -- --file frog.gif --background frog --label "Frog Pond"  # add a local file
npm run sync:assets -- --file rust.gif --icon rust --label "Rust"
```

The script crops backgrounds to 4:1 (stills up to 1600 px, animations up to 640 px), shrinks icons to 128 px and keeps animations. Unchanged sources are skipped. Vector logos are SVGs in `public/assets/devicon`, registered in `lib/catalog.ts`.

### Code map

| Path | |
| --- | --- |
| `lib/banner/schema.ts` | Banner config (zod), 1000×250 canvas |
| `lib/banner/render.ts` | Isomorphic SVG renderer shared by the editor and the API |

| `lib/github/fetch.ts` | GitHub GraphQL, with a fallback to the public contributions page |
| `lib/cards/render.ts` | Widget cards and themes |
| `lib/views.ts` | Profile views counter |
| `components/editor/` | The drag-and-drop editor |
